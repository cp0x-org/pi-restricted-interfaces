About Spark
The Spark Smart Contract Protocol is software source code freely licensed to the public, which provides a decentralized “credit” protocol through which tokens can be ‘loaned' and ‘borrowed' or allocated to automated savings strategies. The Spark Smart Contract System is a copy of the Spark Smart Contract Protocol that has been compiled to bytecode and permanently associated with one or more specific public addresses on Ethereum Mainnet and Spark Altchains. Through a compatible third-party wallet application or device, Ethereum Mainnet Node or node compatible with a Spark Altchain, as applicable, any User may pay Ethereum Mainnet Validators or other validators on the appropriate Blockchain System to operate and record the results of the Spark Smart Contract System in accordance with the User's instructions, thus effectuating token transactions.
Relationship to Spark Smart Contract System
Using Spark Mainnet, Spark Altchains, Ethereum Mainnet, or the Spark Smart Contract System does not require use of the Site. The Site aggregates and publishes publicly available information about the Spark Smart Contract System in a user- friendly and convenient format. Such information is also independently available from other sources—for example, a person may directly review transaction history, account balances and the Spark Smart Contract System on a compatible block explorer for Ethereum Mainnet or a Spark Altchain.
By combining publicly available information with the User's interactions with the Site, the Site can draft standard transaction messages compatible with the Spark Smart Contract System which are designed to accomplish the User's operational goals as expressed through the interactions. If the User so wishes, the User may broadcast such messages to Spark Mainnet or a Spark Altchain in order to initiate token transactions.
All draft transaction messages are delivered by the Site via API to a compatible third-party wallet application or device selected by the User after pressing the “Connect Wallet” (or similar) button on the Site. The User must personally review and authorize all transaction messages that the User wishes to send to Spark Mainnet, Spark Altchains or other blockchain systems; this requires the User to sign the relevant transaction message with a private cryptographic key inaccessible to the Site. The User- authorized message will then be broadcast to Validators through the wallet application or device and the User may pay a network fee to have the Validators apply the transaction message to the Spark Smart Contract System and record the results on the appropriate blockchain—resulting in a token transaction being completed on that blockchain.
